One funny line, at most 200 characters, for [The One-Line Laugh](https://make.fun/competitions/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

## The line

> I hired an AI agent to save me time; it automated my procrastination, so now I do nothing at scale.

## How it works

`main.ts` writes that single sentence to `/output/entry.txt` and prints it.
Run it with Node 22:

```sh
node main.ts
```
